# ⚡ Flash Chat 💬

**Flash Chat**, Flutter ve Firebase kullanarak geliştirilen, gerçek zamanlı bir mesajlaşma uygulamasıdır. Kullanıcılar giriş yapabilir, kayıt olabilir ve anlık mesajlaşabilir.

---

## 🚀 Özellikler

- 🔐 Firebase Authentication ile kullanıcı girişi & kayıt
- 💬 Cloud Firestore ile anlık mesaj gönderimi ve alımı
- 📱 Mobil uyumlu modern arayüz (Flutter)
- 🕒 Mesajlara zaman damgası ekleme

---

## 🛠️ Kullanılan Teknolojiler

- [Flutter](https://flutter.dev/)
- [Firebase Authentication](https://firebase.google.com/products/auth)
- [Cloud Firestore](https://firebase.google.com/products/firestore)
